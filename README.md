# 组合装税费测算工具

这是根据 `(模板)组合装税费测算.xlsx` 制作的本地网页工具。

## 使用方式

1. 双击 `start-windows.bat`。
2. 浏览器会打开本地网页工具。
3. 点击“新建组合装”后，新组合会直接显示在同一个页面下方。
4. 每个组合装只需要填写组合链接实际售价和商品明细。
5. 页面会自动计算分摊结算售价、单位容量售价、结算税率和结算税金。
6. 底部“组合方案对比”会汇总不同组合装的总税金和综合税率。

## 多组合装方案

- `新建组合装`：创建一个空的新方案。
- `复制此组合`：复制对应方案，适合在原方案基础上换一两个商品继续测。
- `删除组合`：删除对应方案，至少会保留一个方案。
- `导出 CSV`：导出所有组合装方案和各自明细。
- `复制结果`：复制所有组合装方案结果，方便粘贴到 Excel 或聊天窗口。

## 计算规则

- 产品售价合计 = 单件产品售价 × 产品数量
- 产品售价所占比例 = 产品售价合计 ÷ 组合装产品售价合计
- 实际结算售价 = 组合链接实际售价 × 产品售价所占比例
- 产品合计克重 = 单件产品克重 × 产品数量
- 单位容量售价 = 实际结算售价 ÷ 产品合计克重
- 税率按产品类型判断，逻辑与“商品利润计算工具”一致
- 结算税金 = 实际结算售价 × 结算税率

默认税率规则：

- 化妆品：单位容量售价小于 10 时用低税率，否则用高税率
- 面膜：单位容量售价小于 15 时用低税率，否则用高税率
- 其他：默认用低税率
- 低税率：9.1%
- 高税率：23.05%

这些税率规则在页面顶部作为参考展示，不需要在每个组合里重复填写。
